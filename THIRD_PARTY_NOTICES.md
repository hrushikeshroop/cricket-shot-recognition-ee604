# Third-party materials

- Primary image dataset: https://www.kaggle.com/datasets/aneesh10/cricket-shot-dataset (version 2). Downloaded metadata reports Unknown license. This project does not grant rights to redistribute the photographs or underlying broadcasts. The raw dataset is excluded from Git. Five selected JPEG examples are included under `demo/images/` for the image demonstration and also appear in the report or slides. Their source labels, variants and hashes are recorded in `demo/image_examples.json`. Other restored image examples remain local. Transformed copies are part of the upstream archive; no synthetic training images were generated here.

- Dataset: https://www.kaggle.com/datasets/amittalmale/cricket-shots (version 1). Kaggle metadata declares CC0. The original broadcasts may carry separate rights, which this project has not verified. Raw clips, standalone example clips, derived thumbnails and UI screenshots are excluded from source-control defaults. The report, slides and selected slide illustrations contain attributed educational examples; their inclusion does not grant rights to the underlying imagery. This local educational project does not grant rights to broadcast footage.
- MobileNetV2 weights: ONNX Model Zoo, Apache 2.0, https://github.com/onnx/models/tree/main/validated/vision/classification/mobilenet. Pretrained on ImageNet. Source graph checksum is recorded in `data/provenance.json`. The frozen feature-output derivative and numeric cricket heads are included for immediate inference. See `models/NOTICE.md` and `models/APACHE-2.0.txt`.
- CVPR 2022 template: unmodified style files from the official author-kit archive are retained in the local report-authoring materials. The final report uses this style; the public repository contains the compiled report. Original template comments and acknowledgements remain intact locally.
- Python packages remain under their respective licenses. See `requirements-lock.txt` and package metadata. Their source is not reproduced as original project code.
- Microsoft PowerPoint is used locally to author and render the presentation. It is not included in the project.
